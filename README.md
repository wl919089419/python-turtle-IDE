# Python Turtle IDE

基于浏览器与 Skulpt 的离线版 Python Turtle 在线/离线集成开发环境。

## 特性

- 🐢 **Python Turtle 绘图**：内置海龟绘图环境，支持常用动作、画笔与填充、常用几何图形等。
- 📐 **内置绘制矩形函数**：支持 `rect(宽度, 高度, x坐标, y坐标, 线宽)`，以 `(x, y)` 作为**左上角**定位起点。线宽为 0 表示实心填充矩形，大于 0 为空心边框。同时支持 `turtle.rect(...)`。
- ✍️ **可视化文字绘制向导 (write)**：代码助手提供字体名称、字体大小、字体类型、对齐方式 4 项可视化下拉框及文本输入，支持动态代码预览与一键插入。内置毛笔书法体 (MaShanZheng)、站酷快乐体 (ZCOOLKuaiLe)、复古像素体 (PressStart2P)、浪漫花体 (Pacifico) 等离线字体库，视觉差异鲜明。
- 🖥️ **自适应居中画布**：调整浏览器窗口尺寸时，绘制的图案平滑居中跟随画布与坐标系原点 (0,0) 同步自适应，图案永不丢失与错位。
- 💾 **全图层导出图片**：一键将背景、线条画迹、填充图形、文字与海龟图标完整叠加导出为高清 PNG 图片。
- 📁 **代码导入与导出**：一键打开/载入本地 `.py` 文件，一键将当前编辑器代码导出为 `.py` 源码。
- 📍 **精准原点坐标系**：坐标系交汇点与海龟初始位置 (0, 0) 绝对对齐，支持 `goto`、`setx`、`sety`、`shape` 等精准坐标与造型控制。
- ⚡ **代码编辑**：支持 Python 语法高亮、自动补全括号、代码折叠与行号。
- 🔀 **丰富代码片段**：内置选择结构（if/else）、循环结构（for/while）、常用几何图形代码模板。
- ⌨️ **支持交互输入**：支持 `int(input(...))` 等交互式数据输入弹窗。
- 📍 **辅助网格坐标系**：可切换显示带有刻度与原点对齐的直角坐标系及鼠标实时坐标探测。
- 💾 **保存图片**：一键将绘制生成的图形导出为 PNG 格式。
- 🔌 **完全离线可用**：所有 CSS、JS 及图标字体均已本地化。

## 部署

纯静态前端项目，可直接部署在 **Cloudflare Pages**、GitHub Pages、Vercel 等任何静态托管平台。
